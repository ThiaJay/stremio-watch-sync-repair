Account reference

CORE TARGET

Validates and repairs the shared Stremio account. The permanent cross-device implementation belongs in Stremio Core, not a device-local daemon.

Reference reconciliation

This local harness is for diagnosis, adversarial verification and one-time account repair while the same behavior is prepared for Stremio Core. It should not be used as a permanent device-specific sync service.

Safety rules: incomplete sources never become unwatched, concurrent Stremio client changes abort the scan, recent LibraryItems are deferred and every mutation is backed up and read back.

Connections and sources

Native Stremio ↔ Trakt integration

Watch Sync & Repair uses the Trakt connection already owned by your Stremio account. You do not need a Trakt API application, client ID, client secret or VIP subscription.

Normal playback is scrobbled to Trakt by Stremio itself. This companion reads Trakt history through Stremio’s own integration and can repair reviewed Trakt → Stremio watched-state differences. Stremio-only historical flags that were never scrobbled are reported rather than pushed with borrowed API credentials.

Choose metadata primary/fallback order in Advanced. Source URLs and optional TMDB tokens are encrypted locally and never shown in status output.
